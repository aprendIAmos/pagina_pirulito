# Pirulito

Primera versión de la landing page de Pirulito, una marca de postres por porción.

## Ver el sitio

Abrí `index.html` en un navegador o levantá un servidor local:

```bash
python -m http.server 8080
```

Luego abrí `http://localhost:8080`.

## Personalización rápida

- **WhatsApp:** el número y los mensajes prearmados están en `script.js`.
- **Precios:** se editan con el atributo `data-price` de cada producto en `index.html`.
- **Fotos:** reemplazá las URLs de `images.unsplash.com` por las fotos reales de Pirulito.
- **Colores y estilos:** están agrupados al inicio de `styles.css` como variables CSS.
- **Redes sociales:** no se incluyen porque la marca todavía no tiene Instagram.

La página es estática y no necesita base de datos para funcionar.
